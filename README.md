# 🖼️ Image Scanner

A powerful web-based image scanner that crawls websites and extracts all images with detailed metadata. Built with Node.js, Express, and modern web technologies.

## Features

✨ **Core Features**
- 🔍 Scan websites for all images (including those in CSS, picture elements, srcsets)
- 🌐 Multi-page crawling with configurable depth
- 📊 Extract comprehensive image metadata (dimensions, file size, content type, HTTP status)
- 📥 Export results as CSV
- 📦 Download ZIP archive with CSV results and optional image files
- ⚡ Concurrent request processing for fast scanning
- 🛡️ Polite crawling with per-domain rate limiting
- 🎨 Dark-themed responsive UI
- 📱 Mobile-friendly interface
- 🔗 Sitemap validation integration with W3C validators

## Requirements

- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher
- **Disk Space**: At least 100MB
- **Internet Connection**: Required for scanning websites
